✅ Regra de ouro: O Phaser gerencia o estado do jogo. O React gerencia a interface. A comunicação é unidirecional via eventos.
🔒 2. Segurança SSR & Next.js App Router
O Phaser acessa window, document e CanvasRenderingContext2D. Nunca deve ser importado ou instanciado no servidor.
A instanciação ocorre exclusivamente dentro de useEffect no "use client", garantindo execução apenas no navegador.
next/dynamic não foi utilizado propositalmente: o useEffect já oferece isolamento mais performático e evita flicker de loading desnecessário para um canvas controlado.
Atenção em rotas dinâmicas: Se o componente for renderizado condicionalmente, o cleanup do useEffect garante que o canvas anterior seja destruído antes da nova montagem.
🌉 3. Ponte Phaser ↔ React (Comunicação)
A comunicação segue o padrão Event-Driven, evitando acoplamento direto de estado:

scoreUpdate e victory são emitidos pela MainScene.
O React escuta via game.events.on('sceneReady', (scene) => { scene.events.on(...) }).
Por que não usar Zustand dentro da Scene?
O Phaser roda em requestAnimationFrame (60fps). Atualizar stores React a cada frame causaria re-renders massivos e travamentos. Eventos discretos (drop, vitória) mantêm a UI sincronizada sem impacto no loop do jogo.
🧹 4. Gerenciamento de Ciclo de Vida & Memory Leaks
Em SPAs e Next.js Client Navigation, múltiplas montagens de canvas são a principal causa de vazamento de memória.
gameRef.current atua como guard para impedir dupla instanciação.
game.destroy(true) no retorno do useEffect:
Remove o <canvas> do DOM
Destrói texturas, tweens, input listeners e cenas
Limpa referências internas do WebGL/Canvas2D
Validação em produção: Monitore Performance > Memory no DevTools. Após navegação de ida/volta, o heap deve retornar ao baseline.

🎨 6. Assets & Geração Procedural
Todas as texturas são geradas via this.make.graphics().generateTexture() no preload().
Vantagens:
Zero requisições HTTP → carregamento instantâneo
Sem problemas de CORS, cache ou SSR
Bundle menor e previsível
Migração para assets reais:
Substitua generateTexture por this.load.image('circle', '/assets/circle.png') e ajuste as dimensões no create(). Mantenha a mesma chave (key) para preservar a lógica.

📦 9. Próximos Passos Recomendados
Áudio: Adicionar this.load.audio() no preload e disparar no handleCorrectMatch. Use formatos .mp3 + .ogg para compatibilidade cross-browser.
Analytics: Emitir eventos customizados (game.events.emit('analytics', { action: 'shape_matched', shape: 'circle' })) para tracking de engajamento.
Dificuldade Progressiva: Adicionar rotação das formas, mais peças ou timer visual (barra de cores, não números).
Testes Automatizados: Mock do Phaser com jest-canvas-mock para testar emissão de eventos da MainScene sem renderizar o engine.
📞 Suporte & Manutenção
Versões validadas: Phaser ^3.70.0, Next.js ^14.2.0, React ^18.3.0, Zustand ^4.5.0
Debug da Scene: Altere arcade: { debug: false } para true em gameConfig.ts para visualizar hitboxes e vetores.
Problemas comuns:
Cannot read properties of undefined (reading 'game') → Phaser instanciado fora do useEffect ou antes do mount.
Canvas duplicado → Cleanup do useEffect não executado (verifique dependências do array).
Touch não responde no iOS → Adicione <meta name="viewport" content="width=device-width, initial-scale=1, maximum-scale=1, user-scalable=no"> no layout.tsx.
